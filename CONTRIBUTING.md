# Contributing

Thanks for helping improve UI UX Pro Max.

- **Issues** are triaged weekly. Clear repro steps and, when relevant, your AI host and `uipro-cli` version help a lot.
- **Pull requests** from forks are welcome. Open an issue for large features before you invest heavy time, so we can align on direction.
- **Tests:** merges may be gated by the suite under `evals/` when present; run it before opening a PR and fix failures you introduce.

For repo layout, sync rules, and how to work on `src/ui-ux-pro-max/` vs `cli/`, read [docs/architecture.md](docs/architecture.md) and [CLAUDE.md](CLAUDE.md).
